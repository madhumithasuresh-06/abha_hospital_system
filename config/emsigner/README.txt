Place your eMudhra emSigner Public Key Certificate (.cer file) in this directory.
File name: emsigner_public.cer
Path configured in .env: config/emsigner/emsigner_public.cer

This certificate contains the RSA public key required by emSigner Signer Gateway to encrypt the session key (Parameter 1) before sending signing requests.
You can obtain it from your emSigner account under Settings / Developer / Certificate management.
